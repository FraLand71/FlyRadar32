# FlyRadar32

**Version 1.2 (Build 694) — ESP-IDF RGB64** · Waveshare ESP32-S3 Touch LCD 7″ (800 × 480)

**[Install FlyRadar32 with Chrome or Edge](https://fraland71.github.io/FlyRadar32/)**

Build 694 is the current web-installable release. It includes the faster flight-detail flow introduced in Build 693, SD EXIO4 chip-select handling improvements, and supplemental ADS-B traffic lookup with ICAO deduplication. The supplemental provider is rate limited and may not increase coverage in every area.

**Previous firmware:** `FlyRadar32_v1_2_Build690_merged.bin` is retained in the repository for rollback. Other historical builds are also preserved.
