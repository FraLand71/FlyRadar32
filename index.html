FLYRADAR32

Flight radar for Waveshare ESP32-S3 Touch LCD 7″ (800 × 480).

Public version 1.0 · Build 594
Install via UART1 — Chrome / Edge
  1. Connect the Waveshare UART1 USB-to-serial port using a data cable.
  2. Close Arduino Serial Monitor or any other software using the serial port.
  3. In desktop Chrome or Edge, click Install and choose the Waveshare serial port.
  4. Follow the prompts, then restart the display.
This installer requires desktop Chrome or Edge with Web Serial support.
Flashing replaces the current firmware and can erase saved Wi-Fi/location preferences. Keep a backup.
Aircraft photo library — microSD

The optional aircraft images are stored on the microSD, not in the firmware. Format the card as FAT32 with an MBR partition table, extract the image archive, and copy the foto_compagnie_aeree folder to the card root.

MicroSD setup instructions · Photo library / Releases
