FLYRADAR32

Flight radar for Waveshare ESP32-S3 Touch LCD 7″ (800 × 480).

Stable firmware · v5.9.2
Install from Chrome or Edge
  1. Connect your Waveshare using its USB-to-UART port, as for Big Plane Radar.
  2. Close Arduino Serial Monitor and other applications using the USB port.
  3. Click the button below and select the connected serial port.
  4. Follow the installation instructions; restart the Waveshare afterward.
Open this page in desktop Chrome or Edge with Web Serial support.
Installing firmware replaces the current firmware and may erase saved Wi-Fi/location settings. Keep a backup.

The airline photo collection stays on your microSD card and is not included in this firmware.

Source repository · Only for the ESP32-S3 Waveshare 7″ hardware.
